# NavKit Demo Mod
This mod replaces the official NAVP, AIRG and CRMD files of vanilla missions with ones generated by [NavKit](https://github.com/glacier-modding/NavKit), for smoke testing NavKit's output in game.

## Usage
1. Install [Simple Mod Framework](https://github.com/atampy25/simple-mod-framework) (SMF).
2. Download the latest release zip file of NavKit Demo Mod.
3. In SMF, import the mod zip file.
4. Press the `Deploy` button and wait for it to finish deploying.
5. Launch Hitman.
6. Enter into any of the missions that have been modified.

## Regenerating the mod
The files under `content` are generated; don't edit them by hand. NavKit's `generate-demo-mod` build target regenerates them:

```powershell
cmake --preset x64-release-demo-mod
cmake --build --preset generate-demo-mod
```

For each mission in `navkit-demo-missions.json`, the generator finds the scene's official NAVP, AIRG and CRMD resources with navkit-rpkg-lib, launches HITMAN on the scene through the ZHMModSDK editor, extracts it, builds a NAVP, an AIRG and a CRMD for each crowd, and writes them to `content/<chunk>/<mission>/<hash>.<type>` under the official hashes. It then runs SMF's `Deploy.exe`, checks the deployed RPKGs hold the generated files, and loads each mission in game as a smoke test.

`navkit-demo-mod.generated.json` records which files belong to which mission, so regenerating a mission replaces only its own files. To add a mission, add its scene to `navkit-demo-missions.json`. To regenerate some missions only, set the CMake cache variable `NAVKIT_DEMO_MOD_ARGS`, for example to `--mission;Arrival`, or run `NavKitDemoModGenerator --help` for all options.

The NavKit Bulk Generation Tool, which the NavKit installer includes, does the same from a window: set its output directory to this mod's `content` folder, queue missions and press Start. It writes files in the same layout, but does not update `navkit-demo-mod.generated.json`.
